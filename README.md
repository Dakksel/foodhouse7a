# Food House — сайт меню

Полностью рабочий сайт-меню для **Food House**.
Заказы уходят в **WhatsApp** на номер **+7 705 136 76 85**.

## Структура папки `Food House/`

```
Food House/
├── index.html         ← главная страница
├── styles.css         ← стили (тёмная тема, жёлтый + красный акценты)
├── script.js          ← меню + корзина + WhatsApp
├── vercel.json        ← конфиг для деплоя
├── README.md          ← этот файл
└── photos/
    ├── logo.jpg       ← логотип (Food House — жёлтый круг)
    └── menu.jpg       ← исходное фото меню
```

## Как запустить локально

Самый быстрый способ — открыть файл напрямую (без сервера):

1. Откройте `D:\Claude projects\1try\Food House\` в Проводнике.
2. Дважды кликните по **`index.html`** — сайт откроется в браузере.

Или локальный сервер (для теста на телефоне):

```powershell
cd "D:\Claude projects\1try\Food House"
python -m http.server 8000
```

Затем `http://localhost:8000` на ПК или `http://<IP-вашего-ПК>:8000` на телефоне в той же Wi-Fi.

## Как задеплоить на Vercel

Сайт полностью статический — нужны только HTML/CSS/JS и папка `photos/`. Папка уже содержит `vercel.json`, который включает чистые URL-ы (`/menu` вместо `/menu.html`).

### Способ 1 — через Git (рекомендуется)

1. Создайте репозиторий на GitHub и запушьте **содержимое** папки `Food House/` (без самой папки-обёртки — `index.html` должен быть в корне репозитория).
2. Зайдите на [vercel.com](https://vercel.com) → **Add New Project** → Import репозитория.
3. Framework Preset: **Other**. Root Directory: оставьте пустым.
4. Нажмите **Deploy**. Через 30 секунд сайт будет доступен по адресу `https://<project-name>.vercel.app`.

### Способ 2 — через Vercel CLI

```powershell
cd "D:\Claude projects\1try\Food House"
npm i -g vercel
vercel login
vercel --prod
```

CLI сам определит статический сайт и задеплоит.

### Способ 3 — Drag & Drop

1. Запакуйте **содержимое** папки `Food House/` (без самой папки) в `.zip`.
2. Зайдите на vercel.com → **Add New Project** → **Import** → **Drag & Drop** этот `.zip`.

## Как изменить меню / цены / номер

- **Цены и позиции** → массив `MENU` в `script.js` (верх файла).
- **Номер WhatsApp** → константа `PHONE` в `script.js` (формат международный, без `+`).
- **Порог бесплатной доставки** → `DELIVERY_THRESHOLD` и `DELIVERY_FEE` в `script.js`.
- **Логотип** → замените файл в `photos/` или измените путь в `<img class="logo-img">` в `index.html`.
- **Цвета / стиль** → CSS-переменные в начале `styles.css` (`--yellow`, `--red`, `--bg`).
